Explorando Redes Neuronales

Esta plataforma interactiva permite visualizar el comportamiento de diferentes arquitecturas de redes neuronales, desde el perceptrón más simple hasta autoencoders de espacio latente.

Perceptrón Simple

La unidad básica de una red neuronal. Aprende a separar datos linealmente mediante el ajuste de pesos y un sesgo.

Perceptrón Multicapa (MLP)

Introduce capas ocultas y funciones de activación no lineales (como tanh) para resolver problemas donde los datos no son linealmente separables.

Autoencoders

Redes diseñadas para aprender representaciones eficientes de datos (compresión) y luego reconstruirlos a partir de un espacio latente reducido.
